# FinancialDS — checklist (self-review перед финишем)

Генерируется tools/gen-consumer-skill.py (рукописная правка поймается воротами).
Прогони каждый свип по СВОЕМУ выводу до сдачи; любой hit — чинить или объяснить в assumptions.

## Свипы (grep по своему .tsx)
1. **Сырые цвета** — `#[0-9a-fA-F]{3,6}` и `rgba?\(`: ожидание 0. Каждый цвет = `var(--ds-*)`.
2. **Disabled через opacity** — `opacity:\s*\.?5`: ожидание 0. Выключение = `--ds-disabled-fill`.
3. **Голый outline** — `outline:`: ожидание 0. Фокус = `box-shadow: var(--ds-focus-ring)`.
4. **z-index > 200** — `z-index:\s*[0-9]+`: значения выше 200 вне шкалы слоёв ДС.
5. **Отступы вне ступеней** — только `--ds-space-*` (1=4px, 2=8, 3=12, 4=16, 5=20, 6=24, 8=32, 10=40, 12=48, 16=64, 24=96); ступень вне шкалы молча рендерится в 0.
6. **Моушен без токенов** — `transition:[^;]*` обязан нести `var(--ds-dur-*)`; easing — `var(--ds-ease)`.

## Семантика (grep не ловит — проверь глазами, правила в SKILL.md)
- Статус текстом = **Tag** со словом из словаря дословно (conventions.md §Status); Badge — только число или точка.
- Ошибки — три части: причина · следующее действие · код.
- Необратимое действие — подтверждение `solid` + `negative`, ярлык «Глагол + Объект».
- Суммы — точные десятичные через Intl.NumberFormat; никаких `1.2k` и молчаливого округления.
