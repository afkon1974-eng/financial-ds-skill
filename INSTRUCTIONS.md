# FinancialDS — always-on rules

Короткий слой для вставки в AGENTS.md / CLAUDE.md / Cursor rules (генерируется
tools/gen-consumer-skill.py; рукописная правка поймается воротами). Полный контракт —
SKILL.md рядом; выбор компонента — catalog-prompt.md; API и темизация — conventions.md.

## Когда применять
- Задача строит экран/страницу/прототип с компонентами FinancialDS, или код экрана обязан
  следовать токен-системе --ds-*.

## Правила (никогда не нарушать)
1. Сначала найди компонент в catalog-prompt.md: задача матчится на `when:`; вето `not-for:`
   сильнее совпадения; `pairs-with:` называет соседей. В вывод идут только `stable`.
2. Бери ТОЛЬКО документированные пропсы (catalog-prompt.md / conventions.md) — не изобретай
   пропсы, варианты и значения.
3. Цвета: никогда не хардкодь; каждый цвет — `var(--ds-*)`.
4. Отступы: только ступени `--ds-space-*` (1=4px, 2=8, 3=12, 4=16, 5=20, 6=24, 8=32, 10=40,
   12=48, 16=64, 24=96). Ступень вне шкалы молча рендерится в 0.
5. Текст: font-size и line-height идут ПАРОЙ из `--ds-type-hN-size` + `--ds-type-hN-lh`.
6. Заголовки — семантические `<h1>`–`<h6>` с `--ds-type-hN-*`; голые span вместо уровней запрещены.
7. Статус текстом = **Tag** (словарь дословно, conventions.md §Status); Badge — только число или точка.
8. Ошибки — три части: причина · следующее действие · код ошибки.
9. Суммы — точные десятичные с разделителями через Intl.NumberFormat из сырых чисел;
   сокращения (`1.2k`) и молчаливое округление запрещены.
10. Главное действие экрана/диалога — `variant="solid" intent="neutral"`; бренд-красный — только
    CTA входа/регистрации (максимум один на экран, никогда внутри модалки/формы/строки таблицы);
    у Button НЕТ `warning` интента.
11. Необратимые действия — через подтверждение: `solid` + `intent="negative"`, ярлык `<Глагол> <Объект>`.
12. Прототип статический: без useState/effects/вычисляемых пропсов; взаимодействие — в assumptions.
13. Если нужного компонента в ДС нет — скажи об этом в assumptions; не подменяй чужим UI-китом.
14. Перед финишем сверь вывод с чек-листом SKILL.md и контрактом вывода (один TSX-файл,
    default export `Screen`, стиль только через `--ds-*`).
